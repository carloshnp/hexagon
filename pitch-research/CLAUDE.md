# CIVITAS — Pitch & Research Workspace

## Contexto / Context
Pesquisa e pitch para o sistema CIVITAS no Claude Impact Lab Rio.
Workspace de escrita — usa Haiku para economizar tokens.

## Objetivo
Documentar o problema, a solução e o impacto do CIVITAS para:
- Juízes do hackathon
- Gestores municipais de segurança pública do Rio
- Apresentação de 5 minutos

## Dados do Problema / Problem Data
- Fonte principal: ISP-RJ (Instituto de Segurança Pública do Rio de Janeiro)
- Site: isp.rj.gov.br
- Dados: ocorrências por delegacia, mês, tipo de crime, bairro

## Documentos a Criar / Documents to Create
- `PITCH_DECK.md` — outline do pitch de 5 minutos
- `PROBLEM_CONTEXT.md` — contexto do problema com dados reais
- `DATA_SOURCES.md` — fontes de dados abertas disponíveis
- `IMPACT_METRICS.md` — métricas de impacto esperado

## Regras de Escrita / Writing Rules
- Tom: profissional, empático com o problema público
- Idioma: Português para pitch, Inglês para docs técnicos
- Dados: citar sempre a fonte original
- Precisão: nunca inventar estatísticas — pesquisar o ISP-RJ
