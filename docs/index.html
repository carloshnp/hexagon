Conceitos Fundamentais / Core Concepts

1.1 Modelos / Models

Claude Code usa modelos da Anthropic. Escolha o modelo certo para cada tarefa para usar seus créditos com eficiência. / Claude Code uses Anthropic models. Choose the right model for each task to use your credits efficiently.

Modelo / Model Velocidade / Speed Custo / Cost Melhor para / Best for
claude-haiku-4-5 ⚡ Muito rápido 💚 Baixo Pesquisa, tarefas simples, bulk
claude-sonnet-4-6 Padrão ⚡ Equilibrado 💛 Médio Geração de código, análise
claude-opus-4-7 🐢 Mais lento 🔴 Alto Arquitetura, raciocínio complexo
💡 Recomendação para o hackathon Use Sonnet para a maioria do trabalho. Reserve Opus para decisões de arquitetura críticas. Use Haiku para pesquisa rápida e tarefas repetitivas. Com $50, você tem margem ampla para iterar.

1.2 Harness

O harness é o ambiente de execução que orquestra o trabalho do Claude. Claude Code É o harness.

💬
Contexto de Conversa
Mantém histórico e estado da sessão. Claude "lembra" do que foi feito.
🔧
Ferramentas / Tools
Controla quais ações Claude pode executar: ler arquivos, rodar código, buscar na web.
🔐
Permissões / Permissions
Define o que é permitido sem aprovação manual — configura via settings.json.
🪝
Hooks
Comandos automáticos que rodam antes/depois de ações específicas.
🧠
Memória / Memory
Persiste informações e decisões entre sessões diferentes.
🤖
Sub-agentes / Sub-agents
Cria instâncias especializadas em paralelo para dividir trabalho complexo.

Isolamento de Workspaces / Workspace Isolation
Por que e como isolar cada workspace para economizar tokens
💰 Por que isso é crítico para um hackathon de $50 Cada skill, CLAUDE.md e arquivo de config que o Claude Code carrega consome tokens de contexto. Skills de geoespacial carregadas no workspace de pitch = tokens queimados sem retorno.

Isolamento total = contexto menor = menos tokens por prompt = mais iterações com $50.

Como o Claude Code Carrega Configurações / Config Loading Hierarchy

O Claude Code acumula configurações em camadas — da mais geral para a mais específica:

Camada / LayerLocalização / LocationEscopo / Scope
Global~/.claude/settings.json
~/.claude/commands/*.md		Todos os projetos — sempre carregado
Projeto.claude/settings.json
.claude/commands/*.md		Este diretório apenas
ContextoCLAUDE.md (atual + pais até git root)Lido em cascata até o git root
⚠️ Armadilha comum / Common trap Skills em ~/.claude/commands/ são carregadas em TODOS os workspaces automaticamente. Se você instalar geoai-skills globalmente, elas aparecerão no workspace de pitch — desperdiçando tokens.

Dashboard web com:
- Mapa de calor interativo filtrável por tipo de crime e período
- Ranking dos 10 bairros com mais ocorrências
- Gráfico de tendência mensal

Stack: FastAPI + SQLite (backend), React + Vite + Leaflet (frontend)

- Funcionar offline com os dados do hackathon

- Nenhum PII nos dados — apenas dados agregados por bairro

9.1 Mapa de Calor de Crimes / Crime Heatmap

Prompt completo para gerar o sistema central do hackathon:

Act as the Backend Engineer.

Implement a FastAPI crime heatmap API based on SPEC.md.

Endpoints to implement:
- GET /api/occurrences?start_date&end_date&crime_type&bairro
  → { total: int, data: Occurrence[] }
- GET /api/stats/by-type
  → { crime_type: count }
- GET /api/stats/by-neighborhood
  → { bairro: { count, lat, lon } }
- GET /api/alerts
  → Alert[] (neighborhoods significantly above historical average)

Data ingestion:
- On startup, scan /data/*.csv and load into SQLite
- Normalize crime_type strings (lowercase, strip whitespace)
- Handle missing lat/lon gracefully (skip the row, log warning)

Include complete Pytest test suite.
Commit each endpoint separately with a descriptive message.
backend prompt

9.2 Detecção de Anomalias / Anomaly Detection

Implement an anomaly detection module for crime data.

Algorithm:
1. Group data by (bairro, crime_type) for the past 90 days
2. For each group, calculate: 30-day rolling average, std deviation
3. Compare current week count to historical average
4. Flag as alert if z-score > 2.0 (high: z>3, medium: z>2)

Output schema for GET /api/alerts:
{
  "bairro": string,
  "crime_type": string,
  "current_week_count": int,
  "historical_avg": float,
  "z_score": float,
  "severity": "high" | "medium",
  "lat": float,
  "lon": float
}

Include Pytest tests with synthetic data that covers:
- Normal distribution (no alerts)
- Single outlier above threshold
- Multiple simultaneous alerts
anomaly detection
